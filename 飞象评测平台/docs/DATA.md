# 数据保留与公开范围

- `server/benchmark.json`：PRD 的 9 条原始 Benchmark Query；首次启动自动加载，无需上传。
- `server/store.js`：可运行的 SQLite 初始化结构、默认评分规则与兼容迁移，保持原实现。
- `database-schema.sql`：当前本地数据库结构的只读快照，可供核对。
- `evaluation-data.json`：现有 3 个真实评测批次、81 条模型调用记录、27 条评分标准记录及评分结果的公开归档；保留失败状态、部分输出、调用参数和费用相关用量。去除了 API 密钥、批次访问 Token 和评审会话 Token。
- 原始 `data/edubench.sqlite`、备份和 `.env` 保留本地；原目录及总仓库本地副本均未删除。现有人评记录为 0，归档没有代填人工分数。

JSON 归档不会在启动时自动覆盖或导入运行数据库。现有本地数据库继续保存完整任务关系和配置；新克隆在首次启动时创建数据库并预置九题，再由管理员配置自己的 API。

机评历史不代表全部任务已完成。GLM 过滤、超时及无效 Judge JSON 等失败如实保留，缺失分数未补零。
