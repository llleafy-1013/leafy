# DOGGO

基于原始 PRD 和静态网页搭建的前端 MVP。无需安装依赖。

## 本地运行

在此目录运行 `python3 -m http.server 8000`，打开 http://localhost:8000 。也可以直接打开 index.html。

## 已实现

- FIND：犬种 / 城市双向探索，关键词搜索、气候与资料状态筛选
- MOVE：目标城市、政策查询入口、运输信息、可保存的搬家清单
- LIVE / CARE：城市探索与基础照护内容
- 我的 DOGGO：个人和狗狗档案、城市和犬种收藏
- 浏览器本地持久化与手机布局

## 数据边界

六座城市和六种狗狗为探索示例。气候匹配仅为启发式，不代表可以合法饲养。原始资料日期和查询入口来自旧项目，未实时核验；城市印象不是统计排名。无账号、云端同步、实时政策、地图或后端。外部图片和字体需要网络。
