# 瑶都

瑶族非遗文化与服饰纹样网站原型，包含纹样、颜色、文化渊源及文创等页面。

## 查看原型

打开 [原型首页](html/主页.html)，或通过本地静态 HTTP 服务访问。`html/` 为原始 Axure 导出，资源相对路径完整保留。

```sh
python3 -m http.server 8000
```

访问 `http://localhost:8000/portfolio/瑶都/html/主页.html`（从总仓库根目录启动服务）。

本目录仅包含网页原型；Axure 源文件、项目申请书与其他私人原稿继续保留在原本地目录，未上传。

## 原始导出状态

原始 Axure 导出已有 14 个不同的资源引用缺失，包含 `resources/scripts/axure/action.js`、`adaptive.js` 及部分纹样 PNG。此次按原样归档，没有修改原始 HTML、生成替代图片或编造资源。部分页面或交互可能不完整，需要从 Axure 源文件重新导出后补齐。
