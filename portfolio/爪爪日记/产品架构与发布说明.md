# 爪爪日记 · Paw Diary

## 可选名称

| 名字 | 定位 |
| --- | --- |
| 爪爪日记（当前采用） | 温暖、直观，突出成长记录 |
| 毛球星球 | 活泼可爱，偏社区与陪伴 |
| 伴宠 | 简洁，适合健康与生活一站式服务 |
| 爪迹 | 强调成长轨迹与宠物足迹 |

## 信息架构

1. 成长档案
   - 宠物切换与资料：昵称、品种、性别、生日、身高、体重、照片。
   - 健康档案：体重趋势、疫苗批次及接种日期、体内外驱虫、洗澡美容。
   - 成长时间线：照片、文字、重要里程碑，按日常和健康筛选。
   - 提醒与建议：自定义护理计划、年龄阶段建议、换牙期与成年期科普。
2. 附近
   - 附近宠友：地域、距离、同品种筛选，好友请求、私聊、拉黑与举报。
   - 宠物友好地点：餐厅、商场、公园、洗护门店、评价与地图导航。
   - 社区日常：发布、浏览、收藏、评论，设置内容可见范围。
3. 宠物医院
   - 医院与兽医资料、执业资质、距离、营业状态、电话、急诊信息。
   - 在线咨询：价格、付费、问诊、订单、退款和评价。
   - 线下就医：导航与预约，急诊优先提示。
4. 我的
   - 账户资料、宠物管理、好友、消息、收藏与订单。
   - 隐私、定位授权、通知、数据导出与账户注销。

## 视觉设计

参考图中的奶油白、蜂蜜黄主色、浅紫与薄荷绿辅助色、大圆角、柔和层次与宠物摄影。桌面采用侧栏和两栏成长工作台，移动端采用底部四项导航。以记录陪伴为主线，将提醒与宠物资料放在容易查看的位置。

## 当前实现与边界

- 已实现：四个页面、响应式布局、编辑名字/品种/体重、文字和照片记录、时间线筛选、本地持久保存、附近演示排序、本地添加演示宠友、地图搜索、数据导出。
- 健康卡片和提醒的初始数值为设计示例；新记录可进入时间线，体重记录会更新体重卡片，其余卡片及提醒尚未按新记录自动计算。
- 医院和附近列表是明确标注的示例，非实时定位或真实医院接诊。
- 尚未实现：身高与生日编辑、多宠物切换、真实身份认证、云同步、即时聊天、公开动态、推送、自定义提醒、医院入驻、付费问诊与订单。
- 页面使用远程字体和 Unsplash 示例图片，加载需要网络。
- 当前是可部署的前端交互原型，不是完整生产服务。

## 文件与运行

发布目录为本文件所在的 outputs 目录。入口 index.html，样式 style.css，交互 app.js。无需安装依赖或构建。
